Critical Fixes (Do these first)
1) Replace unsafe ZIP extraction in `app/core/updater.py`
- Problem: `zipfile.extractall()` allows path traversal entries (ZIP-slip). Updater extracts remote ZIPs — must be hardened.
- Action: Replace `extractall()` with a member-by-member safe extractor that:
  - Normalizes and resolves target paths.
  - Rejects entries that would escape the extraction root (".." or absolute paths).
  - Writes files atomically (write to a `.part` temporary file then replace).
  - Preserves directories and handles directories vs files distinctly.

- Drop-in safe extractor (adapt as needed):

```python
import zipfile, shutil
from pathlib import Path, PurePosixPath

def _safe_extract_zip(zip_path: Path, extract_dir: Path) -> Path:
    extract_dir = extract_dir.resolve()
    with zipfile.ZipFile(zip_path, "r") as zf:
        for member in zf.infolist():
            name = member.filename
            if not name:
                continue
            # Normalize POSIX path inside zip
            safe_parts = [p for p in PurePosixPath(name).parts if p not in ("", ".", "..")]
            target = (extract_dir.joinpath(*safe_parts)).resolve()
            if extract_dir not in target.parents and target != extract_dir:
                raise RuntimeError(f"Unsafe zip entry: {name}")
            if member.is_dir():
                target.mkdir(parents=True, exist_ok=True)
                continue
            target.parent.mkdir(parents=True, exist_ok=True)
            tmp = target.with_suffix(target.suffix + ".part")
            with zf.open(member, "r") as src, tmp.open("wb") as dst:
                shutil.copyfileobj(src, dst, length=1024 * 1024)
            tmp.replace(target)
    return extract_dir
```

- Test: create a ZIP containing `../evil.txt` and verify the extractor raises `RuntimeError` and does not write outside the extraction directory.

2) Add integrity checks for downloaded updates
- Why: ensure updates are authentic and not corrupted.
- Preferred: release a SHA256 file or a GPG signature alongside the ZIP on your release artifacts. Verify the signature or SHA256 before extraction.
- Example SHA256 verification (pseudocode):

```python
import hashlib

def _sha256_of_file(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as f:
        for chunk in iter(lambda: f.read(8192), b""):
            h.update(chunk)
    return h.hexdigest()

expected = read_text_of_remote_sha_file().strip()
if _sha256_of_file(downloaded_zip).lower() != expected.lower():
    raise RuntimeError("Update checksum verification failed")
```

- If you cannot publish a checksum file, at minimum verify a trusted HTTPS download origin, file size sanity checks, and manifest-based validation of required files inside the ZIP before extracting.

3) Move UI network calls off the GUI thread
- Problem: UI modules (examples: `app/ui/music.py`, `app/ui/install_mods_dialog.py`) call `requests.get()` synchronously — blocks Qt event loop.
- Solution: run network I/O in a background `QRunnable` (or `QThread`) and marshal results back via signals. Use `QThreadPool` for simple fire-and-forget work.

- Minimal worker pattern:
```python
from PySide6.QtCore import QObject, Signal, QRunnable, Slot

class WorkerSignals(QObject):
    finished = Signal(object)
    error = Signal(Exception)

class Worker(QRunnable):
    def __init__(self, fn, *args, **kwargs):
        super().__init__()
        self.fn = fn
        self.args = args
        self.kwargs = kwargs
        self.signals = WorkerSignals()

    @Slot()
    def run(self):
        try:
            result = self.fn(*self.args, **self.kwargs)
            self.signals.finished.emit(result)
        except Exception as e:
            self.signals.error.emit(e)
```
- Replace direct `requests.get(...)` calls with a `Worker` that performs the HTTP call and emits the result.

4) Use `requests.Session()` with retries and timeouts
- Pattern reduces connection overhead and adds resilience:

```python
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

s = requests.Session()
retry = Retry(total=3, backoff_factor=0.5, status_forcelist=(429,500,502,503,504))
adapter = HTTPAdapter(max_retries=retry)
s.mount("https://", adapter)
s.mount("http://", adapter)
# use s.get(url, timeout=(5, 30))
```

Packaging & Size Reduction (non-asset recommendations)
- Goal: reduce final distribution size without removing features.

1) Create `requirements-prod.txt`
- Copy only runtime dependencies (exclude dev/test tools like `pytest`, `tox`, etc.)
- Build PyInstaller from a clean venv installed from `requirements-prod.txt` to shrink `PYZ-00.pyz` contents.
- Example commands:
```powershell
python -m venv .venv.build
.\.venv.build\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-prod.txt
pip install pyinstaller
pyinstaller --clean --noconfirm NOTG-Launcher.spec
```
- After build, compare `dist/` sizes to measure wins.

2) Prune PyInstaller `spec` (use `excludes` and explicit `datas`)
- Exclude unused Qt modules that PySide6 may drag in: common candidates:
  - `PySide6.QtWebEngineWidgets`, `PySide6.QtQml`, `PySide6.QtQuick`, `PySide6.QtWebChannel`, `PySide6.QtWebEngineCore`.
- Example `Analysis(..., excludes=[...])` snippet to add to `NOTG-Launcher.spec`:
```python
excludes=[
    'PySide6.QtWebEngineWidgets',
    'PySide6.QtQml',
    'PySide6.QtQuick',
    'PySide6.QtWebEngineCore',
    'PySide6.QtWebChannel',
]
```
- Use `hiddenimports` only when runtime errors require them. Iteratively exclude and rebuild; add modules back if runtime fails.

3) Use `--strip` and optionally UPX (test carefully)
- `--strip` reduces binary size (strip symbols) and works well on Unix; on Windows, `strip` may be limited.
- UPX can compress many binaries; exclude core Qt DLLs if UPX causes runtime issues. Always test the packaged app thoroughly.

4) Make heavy optional libs lazy-imported
- If your app uses optional features (e.g., `yt_dlp` or optional tools), import them only inside the functions that need them. This prevents PyInstaller from including them in `PYZ` unless those code paths are included by analysis.

Reliability, Observability & Diagnostics
1) Add rotating logs
- Use `logging.handlers.RotatingFileHandler` and `platformdirs.PlatformDirs` to place logs in the proper OS location.
```python
import logging
from logging.handlers import RotatingFileHandler
from platformdirs import PlatformDirs
from pathlib import Path

dirs = PlatformDirs(appname="NOTG Launcher", appauthor=False)
log_file = Path(dirs.user_log_dir) / "notg-launcher.log"
log_file.parent.mkdir(parents=True, exist_ok=True)
handler = RotatingFileHandler(log_file, maxBytes=5*1024*1024, backupCount=5, encoding='utf-8')
logging.basicConfig(level=logging.INFO, handlers=[handler])
```
2) Use `logger.exception()` in except blocks so stack traces are captured.
3) Add health/telemetry hooks (local logs only) to capture update failures, installer errors, and session-monitor exits.

Security & Hardening
- Do NOT use `zipfile.extractall()` for remote archives.
- Verify update downloads via SHA256 or signature files. Prefer GPG signatures if you can publish them.
- Run network I/O with TLS verification enabled (do not disable SSL verification).
- Limit IPC token file permissions and lifetime: ensure any `launcher-ipc.json` token files are created with restrictive file permissions and removed when unused.
- Sanitize all external inputs (filenames, URLs, JSON data from third parties).
